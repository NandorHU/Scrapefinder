# Deal Hunter Android v0.1

Natív Android prototípus hibás PS5/Xbox/laptop hirdetések figyeléséhez.

## Benne van
- keresési szabályok kezelése
- max ár beállítás
- HardverApró / Marketplace találati kártyák
- 0–100 deal score
- hibatípus megjelenítése
- értesítés teszt-találatnál
- hirdetés megnyitása böngészőben
- API/backend integrációra előkészített struktúra

## Build
Android Studio -> Open -> projekt mappa -> Build APK.
Min SDK 26, target/compile SDK 35.

## Fontos
A v0.1 helyi prototípus. A tényleges folyamatos HardverApró/Facebook figyeléshez háttérszerver/API kell; ez nincs ebbe a kliens-buildbe beégetve.
